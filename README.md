# Kanban Task Board

A lightweight Kanban task board built with vanilla JavaScript.

The application allows users to create, edit, delete, and reorder tasks using drag and drop. Tasks can be moved between different workflow columns.

## Features

- Create new tasks
- Edit existing tasks
- Delete tasks with confirmation
- Drag and drop tasks
- Move tasks between columns
- Reorder tasks within a column
- Display task count for each column
- Editable task input
- Delete confirmation modal
- Dynamic task creation

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- DOM API
- HTML Drag and Drop API
- MutationObserver
- HTML `<dialog>` element
